# Socle — app v1

Design-led interior styling: from an estate-agency floor plan to a furnished 3D apartment, in four curated styles.

- New here? Read `START-HERE.md`.
- Building with Claude Code? Rules in `CLAUDE.md`, plan in `docs/plan-de-build.md`, spec in `docs/handoff.md`.

```
npm run build
npm run lint
```

Stack: Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Motion · React Three Fiber.
